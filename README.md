Food analyzer app
Quick start:

1. Install deps: npm install
2. Run server/frontend: npm run dev:all

AI USAGE INSTRUCTIONS:

1. Install ollama from https://ollama.com/download2
    a. Download and run the installer
    b. Restart your terminal after installation
2. Open command terminal (cmd in windows, Terminal on Mac/Linux), and run these two commands:
    a. llama pull llama3.2:1b
    b. llama pull llava
    (This will download 5-6GB total and may take 5-10 minutes depending on your internet speed)
3. Start Ollama service:
    a. Windows: Ollama should run automatically
    b. Mac/linux: Run 'ollama serve' in a terminal
4. Everything should be working!
